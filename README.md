# Design and Electrical Layout Planning of a Multi-Unit Residential Building Using AutoCAD

## 📌 Project Overview
This project presents a complete electrical design of a multi-unit residential building using AutoCAD. It includes architectural floor planning, electrical fittings and fixtures layout, conduit design, load calculations, distribution board configuration, and safety systems such as emergency power and lightning protection.

The project aims to provide a practical understanding of real-world electrical planning in residential infrastructure.

---

## 🏗️ Features of the Project

- Complete **floor plan design** (main floor, garage, rooftop)
- Electrical **fittings and fixtures layout**
- **Conduit and wiring layout**
- Emergency electrical line integration
- **Switchboard connection diagrams**
- **Sub Distribution Board (SDB) and Main Distribution Board (MDB) design**
- Emergency distribution system (ESDB, EMDB)
- **Lighting and fan load calculations**
- **Cable and current rating calculations**
- **Lightning protection system design**

## ⚡ Load Calculations

### Lighting Calculation Formula
N = (E × A) / (UF × LLF × n × F)


Where:
- E = Illuminance (lux)
- A = Area (m²)
- UF = Utilization Factor
- LLF = Light Loss Factor
- F = Luminous flux (lumens)

## 🔋 Current & Load Analysis

Formula used:

I = P / (V × pf)


Where:
- P = Power (W)
- V = Voltage (220V)
- pf = Power factor (0.7 assumed)
